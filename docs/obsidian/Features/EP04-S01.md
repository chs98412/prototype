# EP04-S01: 알림 시스템

## 📌 개요

사용자의 활동 알림을 표시하는 피드 페이지. 팔로우, 좋아요, 댓글 등의 활동을 시간 역순으로 표시합니다.

## 💻 구현 코드

### 주요 컴포넌트

| 파일 | 라인 수 | 설명 |
|------|--------|------|
| [NotificationFeed.tsx](../../../frontend/components/notifications/NotificationFeed.tsx) | ~120 | 메인 피드 컴포넌트 |
| [NotificationItem.tsx](../../../frontend/components/notifications/NotificationItem.tsx) | ~80 | 개별 알림 아이템 |

### 기술 스택
- **Frontend**: React, Next.js, TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Supabase Realtime, RPC
- **Database**: PostgreSQL (notifications table)

### 코드 분석

```typescript
// 주요 기능
- 실시간 Supabase 구독 (Realtime)
- RPC: get_notifications()
- 알림 삭제 기능
- 시간 역순 정렬
- 활동 타입별 아이콘 (follow, like, comment)
```
