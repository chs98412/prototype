## User Story

> As a **로그인한 유저**,
> I want to **팔로우한 친구들의 최근 기록을 피드에서 보고 싶다**,
> So that **친구의 취향을 알고 새로운 작품을 발견할 수 있다**.

---

## Acceptance Criteria

- [x] AC1: 홈 피드에 팔로우한 유저들의 최근 기록이 최신순으로 표시된다
- [x] AC2: 각 피드 아이템에 유저명, 작품 포스터, 제목, 상태, 별점, 시간이 표시된다
- [x] AC3: 피드 아이템 클릭 시 해당 작품 상세 페이지로 이동한다

- [x] AC5: 무한 스크롤 또는 "더 보기" 버튼으로 추가 로드된다
