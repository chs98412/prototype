## User Story

> As a **유저**,
> I want to **작품의 상세 정보를 한 페이지에서 확인**하고 싶다,
> So that **시청 여부를 결정하거나 기록을 남길 수 있다**.

## Acceptance Criteria

- [ ] AC1: 포스터, 제목(한/영), 개봉연도, 장르, 줄거리가 표시된다
- [ ] AC2: 감독·주요 출연진이 표시된다
- [ ] AC3: 플랫폼 평균 별점과 평가 수가 표시된다
- [ ] AC4: 최신 리뷰 목록(최대 5개)이 표시된다
- [ ] AC5: 로그인 유저의 경우 내 기록 상태(봄/보는 중/보고 싶음)가 표시된다
- [ ] AC6: 비로그인 상태에서도 페이지 조회가 가능하다 (SEO 대응)

## Technical Notes

- Go 백엔드: `GET /v1/content/:tmdbId` 엔드포인트
- TMDB `/movie/{id}` 또는 `/tv/{id}` 호출, Redis 캐싱 (TTL 24h)
- 평균 별점·리뷰는 자체 DB에서 집계
- Next.js: SSG + ISR (revalidate 24h) — SEO 및 초기 로딩 속도 대응
- URL 패턴: `/content/movie/{tmdbId}`, `/content/tv/{tmdbId}`
