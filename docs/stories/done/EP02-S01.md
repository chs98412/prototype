## User Story

> As a **로그인한 유저**,
> I want to **매일 작품을 기록할 때마다 스트릭이 올라가는 것을 보고 싶다**,
> So that **꾸준히 기록하는 습관을 유지할 동기가 생긴다**.

---

## Acceptance Criteria

- [ ] AC1: 오늘 처음 기록 시 스트릭이 +1 증가한다
- [ ] AC2: 같은 날 여러 번 기록해도 스트릭은 1만 증가한다
- [ ] AC3: 하루 기록이 없으면 스트릭이 0으로 초기화된다
- [ ] AC4: 홈 화면에 현재 스트릭 수와 🔥 이모지가 표시된다
- [ ] AC5: 스트릭이 7, 30, 100일 달성 시 축하 메시지가 표시된다

---

## Technical Notes

- Go 백엔드: 기록 upsert 시 `POST /v1/streaks/log` 호출
- DB: `user_streaks` 테이블 (user_id, current_streak, longest_streak, last_logged_date)
- 로직: last_logged_date가 어제면 +1, 오늘이면 skip, 그 이전이면 reset to 1
- 프론트엔드: 홈 화면에 스트릭 위젯
