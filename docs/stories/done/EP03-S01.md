## User Story

> As a **로그인한 유저**,
> I want to **다른 유저를 팔로우**하고 싶다,
> So that **친구의 활동을 피드에서 볼 수 있다**.

---

## Acceptance Criteria

- [ ] AC1: 유저 프로필 페이지에서 팔로우/언팔로우 버튼이 표시된다
- [ ] AC2: 팔로우 시 즉시 UI에 반영된다 (낙관적 업데이트)
- [ ] AC3: 팔로워 수 / 팔로잉 수가 프로필에 표시된다
- [ ] AC4: 자기 자신은 팔로우할 수 없다
- [ ] AC5: 프로필 페이지에서 해당 유저의 최근 기록 목록이 표시된다

## Technical Notes

- DB: `user_follows` (follower_id uuid, following_id uuid, created_at)
- DB: `user_profiles` (user_id, display_name, avatar_url)
- Supabase Auth의 user_metadata에서 display_name 동기화
- URL 패턴: `/profile/{userId}` (타인), `/profile` (본인)
- Server Action: followUser, unfollowUser
