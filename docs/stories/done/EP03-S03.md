## User Story

> As a **로그인한 유저**,
> I want to **내 장르별 취향 레이팅을 확인**하고 싶다,
> So that **내 영화 취향을 한눈에 파악하고 다른 유저와 비교할 수 있다**.

## Acceptance Criteria

## Technical Notes

- 장르 데이터: TMDB 장르 ID 활용 (user_records에 genre_ids 컬럼 추가)
- 레이팅 산출: (기록 수 × 0.4 + 평균 별점 × 0.6) → Lv.1~5 구간화
- Supabase RPC `get_genre_ratings(p_user_id)` 함수로 집계
- genre_ids는 기록 저장 시 TMDB API에서 함께 저장
