## User Story

> As a **로그인한 유저**,
> I want to **내가 기록한 작품 목록과 통계를 한눈에 보고 싶다**,
> So that **나의 시청 이력을 체계적으로 관리할 수 있다**.

---

## Acceptance Criteria

- [x] AC1: 프로필 페이지에 "봄 / 보는 중 / 보고 싶음" 탭별 기록 목록이 표시된다
- [x] AC2: 각 탭에서 포스터 그리드로 작품을 탐색할 수 있다
- [x] AC3: 통계 섹션에 총 기록 수, 평균 별점, 총 시청 시간(분 단위 추정)이 표시된다
- [x] AC4: 기록 아이템 클릭 시 작품 상세 페이지로 이동한다
- [x] AC5: 다른 유저의 프로필에서도 "봄" 탭 목록만 공개 표시된다

## Technical Notes

- 프로필 페이지(`/profile/[userId]`)에 탭 UI 추가
- Supabase: `user_records` 테이블 status 필터
- 시청 시간 추정: 영화 평균 110분, 시리즈 에피소드 평균 45분 (미디어 타입 기준 고정값)
- 통계 집계: Supabase `count()`, `avg(rating)` 쿼리
