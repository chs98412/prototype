## Technical Notes

### 파일 구조

```
src/
  design-system/
    theme.config.ts       ← 유일한 진실의 원천 (Single Source of Truth)
    tokens.css            ← CSS 변수 정의
    components/
      Logo/
        LogoDefault.tsx
        LogoMinimal.tsx   ← 추후 추가 가능
        index.tsx         ← theme.config 보고 올바른 로고 export
```

### theme.config.ts 구조

```ts
export const theme = {
  colors: {
    primary:    '#FF5733',
    background: '#FFFFFF',
    surface:    '#F5F5F5',
    text:       '#1A1A1A',
    textMuted:  '#6B6B6B',
    border:     '#E5E5E5',
    accent:     '#FFC107',   // 별점용
  },
  typography: {
    fontFamily: 'Pretendard, Inter, sans-serif',
    baseSize:   '16px',
  },
  logo: {
    variant:   'default',    // 'default' | 'minimal' | 'dark'
    wordmark:  'Logged',
  },
  layout: {
    nav:          'bottom-tab',  // 'bottom-tab' | 'top-bar' | 'sidebar'
    card:         'poster',      // 'poster' | 'list' | 'grid'
    borderRadius: '12px',
    spacing:      '4px',         // 기본 spacing unit
  },
}
```

### tokens.css 구조

```css
:root {
  --color-primary:    #FF5733;
  --color-background: #FFFFFF;
  --color-surface:    #F5F5F5;
  --color-text:       #1A1A1A;
  --color-text-muted: #6B6B6B;
  --color-border:     #E5E5E5;
  --color-accent:     #FFC107;
  --border-radius:    12px;
  --font-family:      'Pretendard', 'Inter', sans-serif;
}
```

### tailwind.config.ts 연동

```ts
export default {
  theme: {
    extend: {
      colors: {
        primary:    'var(--color-primary)',
        background: 'var(--color-background)',
        surface:    'var(--color-surface)',
        text:       'var(--color-text)',
        muted:      'var(--color-text-muted)',
        border:     'var(--color-border)',
        accent:     'var(--color-accent)',
      },
      borderRadius: {
        DEFAULT: 'var(--border-radius)',
      },
    },
  },
}
```

### 이후 모든 컴포넌트 규칙

```tsx
// ❌ 금지
<div style={{ color: '#FF5733' }}>
<div className="text-[#FF5733]">

// ✅ 허용
<div className="text-primary">
<div className="bg-surface">
```
