## Dev Notes

### 구현된 파일
- `backend/main.go` — Gin 서버, CORS 설정, 라우팅
- `backend/middleware/auth.go` — Supabase JWT 검증 (HS256)
- `backend/handler/health.go` — GET /health
- `backend/Dockerfile` — 멀티스테이지 빌드 (alpine)
- `backend/fly.toml` — Fly.io 배포 설정 (nrt 리전, 256MB)

### 로컬 실행
```bash
cd backend
SUPABASE_JWT_SECRET=your-jwt-secret go run .
```

### Fly.io 배포 절차
```bash
# 1. flyctl 설치 (https://fly.io/docs/hands-on/install-flyctl/)
brew install flyctl

# 2. 로그인
fly auth login

# 3. 앱 생성 (최초 1회)
cd backend
fly launch --name logged-backend --region nrt --no-deploy

# 4. 환경변수 설정
fly secrets set SUPABASE_JWT_SECRET=your-jwt-secret
fly secrets set ALLOWED_ORIGINS=https://your-vercel-app.vercel.app

# 5. 배포
fly deploy
```

### 환경변수
- `SUPABASE_JWT_SECRET` — Supabase 대시보드 → Settings → API → JWT Secret
- `ALLOWED_ORIGINS` — 쉼표 구분 허용 origin (프로덕션 도메인)
- `PORT` — 기본값 8080
