## User Story

> As a **로그인한 유저**,
> I want to **작품의 시청 상태를 기록하고 별점을 남기**고 싶다,
> So that **내 감상 이력을 관리하고 게임화 기능의 기반 데이터를 쌓을 수 있다**.

## Technical Notes

- Go 백엔드:
  - `POST /v1/records` — 기록 생성/수정 (upsert)
  - `DELETE /v1/records/:id` — 기록 삭제
- DB: `user_records` 테이블 upsert (user_id + tmdb_id unique)
- 별점: 0.5점 단위 → DB에 float 저장 (0.0 ~ 5.0)
- 기록 저장 시 트리거:
  1. `streaks` 테이블 업데이트
  2. 도전과제 진척도 비동기 계산 (고루틴)
- 프론트엔드: 별점 컴포넌트 (half-star 지원)

## Dev Notes

### 구현된 파일
- `supabase/migrations/001_user_records.sql` — user_records 테이블 + RLS 정책
- `frontend/app/actions/records.ts` — Server Actions: upsertRecord, deleteRecord
- `frontend/components/content/StarRating.tsx` — 0.5점 단위 반별 별점 컴포넌트
- `frontend/components/content/RecordSection.tsx` — 상태 선택 + 별점 통합 클라이언트 컴포넌트
- `frontend/app/content/[type]/[id]/page.tsx` — RecordSection으로 교체

### 동작 방식
1. 상세 페이지 로드 시 RecordSection이 Supabase에서 기존 기록 조회 (클라이언트 사이드)
2. 상태 버튼 클릭 → 낙관적 UI 업데이트 → Server Action으로 upsert
3. "봄" 선택 시 별점 UI 표시, 반별 클릭 가능 (0.5점 단위)
4. "삭제" 버튼으로 기록 제거
