## User Story

> As a **movie enthusiast**,
> I want to **see reviews in a magazine-style layout**,
> So that **I can read and appreciate friend reviews in a more engaging format**.

---

## Description

리뷰를 더 매거진/에디토리얼 스타일로 표시. 큰 포스터 + 인용문 박스 + 리뷰 텍스트를 보여주기.

**기능**:
- 왼쪽: 포스터 (160px)
- 오른쪽: 인용문 박스 + 리뷰 텍스트
- 리뷰어 정보 (아바타 + 이름 + 시간)
- 좋아요 + 댓글 버튼
- 반응형 (모바일은 세로, 데스크톱은 좌우)

**참고**: `docs/design-specs/P5-FeedEditorialLayout.md` 참조

## Technical Notes

**컴포넌트 구조**:
```
EditorialReviewFeed (페이지)
├── ReviewCard (각 리뷰)
│   ├── ReviewHeader (리뷰어 정보)
│   ├── ReviewContent (포스터 + 인용문 + 텍스트)
│   └── ReviewActions (좋아요, 댓글)
```

**데이터 흐름**:
```
Supabase RPC (get_friend_reviews)
  ↓
EditorialReviewFeed State
  ↓
ReviewCard 컴포넌트 렌더링
```

**API**:
- **RPC**: `get_friend_reviews(p_user_id, p_limit, p_offset)`
- 조인: reviews + user_profiles + user_records (포스터 경로)

**라이브러리**:
- Framer Motion (좋아요 애니메이션)
- react-markdown (리뷰 포매팅, 선택)

## Design Spec

참조: [`docs/design-specs/P5-FeedEditorialLayout.md`](../design-specs/P5-FeedEditorialLayout.md)

**핵심 UI 요소**:
- 포스터: 160px, 라운드 코너, 그림자
- 인용문: 회색 배경 (#f5f5f5), 좌측 보더, 이탤릭
- 텍스트: 1.8 line-height, pre-wrap
- 반응형: 모바일 세로 → 데스크톱 좌우

**색상**:
- 인용문 배경: #f5f5f5
- 보더: #999
- 텍스트: #333
- 타임스탬프: #666
