## User Story

> As a **로그인한 유저**,
> I want to **작품을 기록하면 관련 도전과제 진척도가 자동으로 올라가는 것을 보고 싶다**,
> So that **별도 행동 없이 자연스럽게 도전과제를 진행할 수 있다**.

---

## Acceptance Criteria

- [ ] AC1: "봄" 상태로 기록 시 관련 도전과제 진척도가 +1 된다
- [ ] AC2: 기록 삭제 시 진척도가 -1 된다
- [ ] AC3: 도전과제 달성(100%) 시 뱃지가 지급되고 알림이 표시된다
- [ ] AC4: 진척도 업데이트는 기록 저장 후 비동기로 처리된다 (응답 지연 없음)
- [ ] AC5: 작품 상세 페이지에서 이 작품이 포함된 도전과제 목록이 표시된다

---

## Technical Notes

- Go 백엔드: 기록 저장 후 고루틴으로 비동기 진척도 계산
  - `POST /v1/records` → goroutine: `updateChallengeProgress(userID, tmdbID)`
- DB: `user_challenge_progress` (user_id, challenge_id, current_count, completed_at)
- 달성 판정: current_count >= challenge.required_count
- 프론트엔드: 작품 상세 페이지 하단에 "관련 도전과제" 섹션 추가
