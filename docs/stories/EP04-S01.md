## User Story

> As a **movie enthusiast**,
> I want to **see notifications about friend activities** (follows, likes, comments),
> So that **I can stay updated on my community and engage with friends**.

---

## Description

사용자의 모든 활동 알림을 실시간으로 표시하는 전용 페이지 구현.

**기능**:
- 팔로우, 좋아요, 댓글 등의 알림 표시
- 프로필 사진 + 액션 텍스트 + 상대 시간 (예: "2일 전")
- 실시간 업데이트 (Supabase Realtime)
- 알림 삭제 기능
- 알림 클릭 → 관련 페이지로 이동

**참고**: `docs/design-specs/P1-NotificationFeed.md` 참조

## Technical Notes

**컴포넌트 구조**:
```
NotificationFeed (페이지)
├── NotificationItem (각 알림)
│   ├── Avatar (프로필 사진, 32px)
│   ├── ActionText (사용자명 + 동작)
│   ├── Timestamp (상대 시간)
│   └── MenuIcon (삭제 버튼)
```

**API 설계**:
- **RPC**: `get_notifications(limit: 20, offset: 0)`
  - 반환: `[{ id, user_id, user_name, user_avatar, type, action_text, created_at, related_id }]`

**데이터베이스**:
- 기존 테이블: `notifications` (user_id, type, recipient_id, related_id, created_at 등)
- 새 컬럼 필요 시: `notifications.action_text` (선택) 또는 RPC에서 계산

**Realtime 구독**:
```ts
supabase
  .from('notifications')
  .on('INSERT', (payload) => {
    // 새 알림 추가
    setNotifications([payload.new, ...notifications]);
  })
  .subscribe();
```

**라이브러리**:
- Framer Motion (스위프 애니메이션, 선택)
- Intersection Observer (무한 스크롤)
