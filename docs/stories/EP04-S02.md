## User Story

> As a **movie enthusiast**,
> I want to **toggle between list and grid views on search results**,
> So that **I can browse movies in my preferred layout**.

---

## Description

기존 검색 결과 리스트 뷰 외에 그리드 뷰를 추가. 사용자가 두 뷰 사이를 전환할 수 있도록 버튼 추가.

**기능**:
- 검색 헤더에 리스트/그리드 뷰 전환 버튼
- 그리드: 2×2 레이아웃 (모바일), 3×3 (태블릿), 4×4 (데스크톱)
- 각 카드: 포스터 + 제목 + 메타정보
- LocalStorage에 뷰 모드 저장 (다음 방문시 유지)
- 스무드 애니메이션 전환

**참고**: `docs/design-specs/P2-SearchGridView.md` 참조

## Technical Notes

**컴포넌트 구조**:
```
SearchPage
├── SearchHeader (수정)
│   ├── 검색바
│   └── ViewToggle (리스트/그리드 버튼)
├── MovieListView (기존)
│   └── MovieListItem
└── MovieGridView (신규)
    └── MovieGridCard
```

**CSS Grid 레이아웃**:
```tsx
const gridLayout = {
  mobile: 'grid-template-columns: repeat(2, 1fr)',
  tablet: 'grid-template-columns: repeat(3, 1fr)',
  desktop: 'grid-template-columns: repeat(4, 1fr)'
};
```

**LocalStorage**:
```ts
const [viewMode, setViewMode] = useState<'list' | 'grid'>(() => {
  return localStorage.getItem('searchViewMode') || 'list';
});

useEffect(() => {
  localStorage.setItem('searchViewMode', viewMode);
}, [viewMode]);
```

**성능 최적화**:
- Virtual scrolling (react-window) 추천
- 이미지 lazy loading
- 메모이제이션 (React.memo)

## Design Spec

참조: [`docs/design-specs/P2-SearchGridView.md`](../design-specs/P2-SearchGridView.md)

**핵심 UI 요소**:
- SearchHeader: 뷰 전환 버튼 (리스트 📋 / 그리드 ⊟)
- MovieGridCard: 포스터 + 제목 (1-2줄) + 메타정보
- 카드 간격: 4px
- 포스터 비율: 9:16 (기본)
- 호버 상태: 그림자 증가

**색상**:
- 활성 버튼: 파란색 (#007AFF)
- 비활성 버튼: 회색 (#E8E8E8)
- 텍스트: #333
- 메타: #999
