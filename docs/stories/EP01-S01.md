## User Story

> As a **신규 방문자**,
> I want to **Google 또는 Kakao 계정으로 간편하게 가입/로그인**하고 싶다,
> So that **별도 비밀번호 없이 빠르게 서비스를 시작할 수 있다**.

---

## Acceptance Criteria

- [ ] AC1: "Google로 시작하기" 버튼 클릭 시 Google OAuth 흐름이 시작된다
- [ ] AC2: "카카오로 시작하기" 버튼 클릭 시 Kakao OAuth 흐름이 시작된다
- [ ] AC3: 최초 로그인 시 users 테이블에 유저 레코드가 생성된다
- [ ] AC4: 로그인 성공 후 홈 화면으로 리다이렉트된다
- [ ] AC5: 로그인 상태에서 앱을 다시 열면 자동 로그인된다
- [ ] AC6: 로그아웃 시 세션이 삭제되고 랜딩 페이지로 이동한다

---

## Technical Notes

- Supabase Auth 사용 (Google, Kakao OAuth Provider 설정 필요)
- 프론트엔드: `@supabase/ssr` 패키지로 Next.js App Router와 통합
- 백엔드: Supabase JWT를 Go 미들웨어에서 검증 (`SUPABASE_JWT_SECRET` 환경변수)
- Kakao OAuth는 Supabase에서 Custom OAuth Provider로 설정 필요

## UX Spec

### Design System
- Primary: `#FF5733` / Background: `#FFFFFF` / Text: `#1A1A1A` / Secondary text: `#6B6B6B`
- Font: Pretendard / Border radius: 12px (card), 9999px (pill)

### Flow
```
Landing Screen → "무료로 시작하기" → Login Screen → Google/Kakao 선택 → OAuth → Home
```

### Screen 1: Landing
- 로고 ("Logged" + 필름 아이콘), 헤드라인, 서브 헤드라인

- CTA 버튼: "무료로 시작하기" (Primary, 전체 너비, 56px)

- "시작하는 방법을 선택하세요"
