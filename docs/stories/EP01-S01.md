## User Story

> As a **신규 방문자**,
> I want to **Google 또는 Kakao 계정으로 간편하게 가입/로그인**하고 싶다,
> So that **별도 비밀번호 없이 빠르게 서비스를 시작할 수 있다**.

## Technical Notes

- Supabase Auth 사용 (Google, Kakao OAuth Provider 설정 필요)
- 프론트엔드: `@supabase/ssr` 패키지로 Next.js App Router와 통합
- 백엔드: Supabase JWT를 Go 미들웨어에서 검증 (`SUPABASE_JWT_SECRET` 환경변수)
- Kakao OAuth는 Supabase에서 Custom OAuth Provider로 설정 필요
