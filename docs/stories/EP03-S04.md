## User Story

> As a **로그인한 유저**,
> I want to **친구와 취향 유사도를 확인하고 싶다**,
> So that **같은 취향의 친구를 발견하고 작품을 추천할 수 있다**.

---

## Acceptance Criteria

- [ ] AC1: 친구 프로필 페이지에 취향 궁합 % 가 표시된다
- [ ] AC2: 궁합은 공통으로 기록한 작품의 별점 유사도 기반으로 산출된다
- [ ] AC3: 공통 기록 작품이 5개 미만이면 "데이터 부족" 표시된다
- [ ] AC4: 궁합 % 클릭 시 공통으로 본 작품 목록이 표시된다

## Technical Notes

- Supabase RPC `get_taste_match(p_user_id, p_friend_id)`:
  - 공통 tmdb_id 추출 (두 유저 모두 기록한 작품)
  - 별점 차이 평균: 1 - (avg(abs(r1.rating - r2.rating)) / 5) → 0~1
  - 공통 5개 미만 → null 반환
- 친구 프로필 페이지에서 팔로우 상태일 때만 표시
