## Acceptance Criteria

- [ ] AC1: 365일 히트맵 그리드 레이아웃 (7열×52행, 색상 강도 5단계)

- [ ] AC3: 년도 선택 UI (이전/다음 버튼, 년도 표시)
- [ ] AC4: 통계 카드 섹션 (음반 수, 곡 수, 평균 평점, 활동 일수)
- [ ] AC5: 셀 호버/클릭 피드백 (툴팁 또는 상세 팝업)
- [ ] AC6: 모바일 반응형 (히트맵 좌우 스크롤, 통계는 스택)
