## User Story

> As a **로그인한 유저**,
> I want to **작품에 짧은 리뷰를 남기고 싶다**,
> So that **내 감상을 기록하고 다른 유저와 공유할 수 있다**.

---

## Acceptance Criteria

- [x] AC1: 작품 상세 페이지에서 리뷰를 작성할 수 있다 (최대 500자)
- [x] AC2: 스포일러 포함 여부를 토글로 설정할 수 있다
- [x] AC3: 스포일러 리뷰는 "스포일러 보기" 버튼을 눌러야 내용이 표시된다
- [x] AC4: 작품 상세 페이지에 해당 작품의 리뷰 목록이 표시된다
- [x] AC5: 본인 리뷰는 수정 및 삭제가 가능하다

---

## Technical Notes

- Supabase: `reviews` 테이블 (user_id, tmdb_id, media_type, content, is_spoiler, created_at)
- RLS: 본인 리뷰만 수정/삭제 가능
- 리뷰 목록: 최신순 정렬, limit 10
