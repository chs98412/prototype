## User Story

> As a **유저**,
> I want to **영화·시리즈·예능 제목으로 검색**하고 싶다,
> So that **기록하거나 탐색하고 싶은 작품을 빠르게 찾을 수 있다**.

---

## Acceptance Criteria

- [ ] AC1: 검색창에 텍스트 입력 시 실시간(debounce 300ms)으로 결과가 표시된다
- [ ] AC2: 검색 결과에 포스터 이미지, 제목, 개봉연도, 타입(영화/시리즈/예능)이 표시된다
- [ ] AC3: 한국어 제목과 영어 제목 모두로 검색 가능하다
- [ ] AC4: 결과가 없을 때 "검색 결과가 없어요" 메시지가 표시된다
- [ ] AC5: 검색 결과 클릭 시 작품 상세 페이지로 이동한다
- [ ] AC6: 비로그인 상태에서도 검색이 가능하다

---

## Technical Notes

- Go 백엔드: `GET /v1/content/search?q={query}&type={movie|tv|all}` 엔드포인트
- TMDB `/search/multi` API 호출 후 Redis 캐싱 (TTL 1h, 키: `tmdb:search:{query}`)
- 포스터 이미지: TMDB 이미지 CDN 직접 사용 (`https://image.tmdb.org/t/p/w300{poster_path}`)
- 프론트엔드: 검색창 debounce 300ms 적용
