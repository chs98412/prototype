---

## 1. Executive Summary

영화·시리즈·예능 콘텐츠를 기록하고 평가하는 플랫폼. 왓챠피디아·레터박스를 벤치마킹하되, 기존 서비스의 핵심 문제인 **낮은 재방문율**을 게임화(Gamification)로 해결한다. 유저가 영화를 보지 않는 날에도 플랫폼에 들어오게 만드는 것이 핵심 목표다.

---

## 2. Problem Statement

왓챠피디아·레터박스 같은 콘텐츠 평점 서비스는 "보기 전 탐색"과 "보고 나서 기록" 두 순간에만 방문이 집중된다. 영화 시청 주기가 길어질수록 방문 빈도도 함께 줄어드는 구조적 문제가 있다. 평점·리뷰 외에 유저를 끌어당기는 콘텐츠나 동기가 부족하기 때문이다.

---

## 3. Goals & Success Metrics

| Goal | Metric | Target (6개월) |
|---|---|---|
| 재방문율 향상 | 주간 활성 유저 / 월간 활성 유저 (WAU/MAU) | > 40% |
| 핵심 유저 확보 | 월 활성 유저 (MAU) | 10,000명 |
| 게임화 참여율 | 도전과제 1개 이상 진행 중인 유저 비율 | > 60% |
| 기록 활성화 | 유저 1인당 평균 기록 작품 수 | > 20편 |
| 수익 | 광고 노출 기반 월 수익 | 측정 시작 |

---

## 4. User Personas

### Persona 1: 마니아 민준 (핵심 타겟)
- **나이**: 25~35세
- **특징**: 월 10편 이상 시청, 감독·배우 필모그래피를 꿰고 있음, 영화 커뮤니티 활동 경험 있음
- **Goals**: 자신의 취향과 감상 이력을 체계적으로 관리하고 싶다. 같은 취향의 사람들과 연결되고 싶다.
- **Pain Points**: 기존 서비스는 기록하고 나면 할 게 없다. 내 취향이 얼마나 넓은지 보여줄 방법이 없다.
- **핵심 욕구**: 자신의 영화 이력이 "자산"처럼 느껴졌으면 좋겠다.

### Persona 2: 라이트 유저 지은 (확장 타겟, MVP 이후)
- **나이**: 20~30세
- **특징**: 월 2~3편, 넷플릭스 위주, 추천받아서 봄
- **Goals**: 뭘 볼지 쉽게 찾고 싶다. 친구들이 뭘 보는지 궁금하다.
- **Pain Points**: 고르는 데 너무 오래 걸린다.

## 5. Epics & Features

### Epic 1: 콘텐츠 기록 & 평점 — Must Have

기본적인 왓챠피디아·레터박스 기능. 이게 없으면 게임화도 없다.

**Features**:
- [ ] 영화·시리즈·예능 검색 (글로벌 DB, TMDB API 활용 검토)
- [ ] 시청 기록 (봄 / 보는 중 / 보고 싶음)
- [ ] 별점 평가 (0.5점 단위, 5점 만점)
- [ ] 짧은 리뷰 작성 (스포일러 접기 옵션 포함)
- [ ] 작품 상세 페이지 (기본 정보, 출연진, 평균 평점, 리뷰 목록)
- [ ] 내 기록 페이지 (시청 목록, 평균 평점, 통계)

---

### Epic 2: 게임화 — 컬렉션 & 도전과제 — Must Have

**E2-1. 도전과제 & 뱃지** (Steam 참고)
- [ ] 사전 정의된 도전과제 제공 (예: "크리스토퍼 놀란 필모 완주", "칸 황금종려상 수상작 10편", "1980년대 홍콩 누아르 5편")
- [ ] 진척도 표시 (9/12편 완료)
- [ ] 달성 시 뱃지 지급, 프로필에 표시
- [ ] 도전과제 카탈로그 탐색 페이지

**E2-2. 필모그래피 도장깨기** (포켓몬 도감 참고)
- [ ] 감독·배우별 필모그래피 컬렉션 페이지
- [ ] 본 작품 / 안 본 작품 시각적 구분
- [ ] 완주율 퍼센트 표시

**E2-3. 활동 히트맵** (GitHub 잔디 참고)
- [ ] 연간 시청 활동 히트맵 (날짜별 기록 시각화)
- [ ] 프로필 페이지에 표시

**E2-4. 연간 시청 목표** (Goodreads Reading Challenge 참고)
- [ ] 연초에 "올해 N편 보기" 목표 설정
- [ ] 진척도 바 표시
- [ ] 연말 목표 달성 여부 공유 카드

**E2-5. 연간 리포트** (Spotify Wrapped 참고)
- [ ] 연말 "나의 한 해 영화 취향 분석" 자동 생성
- [ ] 최다 본 장르, 최고 평점 작품, 총 시청 시간 등
- [ ] 공유 가능한 이미지 카드 생성

---

### Epic 3: 게임화 — 경쟁 & 소셜 — Must Have

**E3-1. 취향 레이팅** (체스닷컴 참고)
- [ ] 유저의 평점 패턴 기반 취향 점수 산출
- [ ] 장르별 취향 레이팅 표시 (예: "공포 마니아 Lv.4")

**E3-2. 친구 시스템**
- [ ] 팔로우 / 팔로워
- [ ] 친구의 최근 기록 피드

**E3-3. 취향 궁합**
- [ ] 친구와 취향 유사도 % 표시
- [ ] "나와 취향 비슷한 유저" 추천

**E3-4. 스트릭** (Duolingo 참고)
- [ ] 연속 기록 일수 표시
- [ ] 스트릭 유지 알림

---

### Epic 4: 토론 시스템 — Could Have (MVP 이후)

- [ ] 작품 단위 토론 스레드 (Reddit 스타일, 투표 기반 정렬)
- [ ] 주제별 토론 분리 (엔딩 해석, 연출, OST 등)

## 6. 핵심 사용자 여정

### Journey 1: 마니아 민준의 하루 (영화 안 보는 날)
```
1. 앱 열기 → 활동 히트맵 확인 ("오늘 빈칸이네")
2. 도전과제 페이지 → "놀란 필모 9/12" 확인
3. 안 본 3편 중 하나 → 왓치리스트에 추가
4. 친구 피드 → 친구가 새 작품 5점 줌 → 관심 생김
5. 앱 종료 (영화는 안 봤지만 10분 사용)
```

### Journey 2: 마니아 민준의 영화 본 날
```
1. 영화 봄
2. 앱 열기 → 검색 → 기록
3. 별점 + 짧은 리뷰 작성
4. 도전과제 진척도 업데이트 확인 ("10/12!")
5. 뱃지 획득 알림
```

## 7. Non-Functional Requirements

### 7.1 Performance
- 작품 검색 응답: < 300ms
- 페이지 초기 로드: < 2초 (모바일 기준)

### 7.2 Platform
- **모바일 퍼스트 웹앱** (반응형)
- PWA 지원 검토 (홈 화면 추가, 오프라인 기본 기능)
- 지원 브라우저: Chrome, Safari 최신 2버전

### 7.3 Availability
- 목표 업타임: 99.5%

### 7.4 Security
- 회원가입/로그인: 이메일 + 소셜 로그인 (Google, Kakao 검토)
- 개인정보: GDPR 기본 준수

### 7.5 Scalability
- 초기: 동시 접속 500명 수준
- 6개월 목표: 동시 접속 2,000명
