# 포스트 작성 에디터 화면 구현

에세이/한줄평/로그/인용/컬렉션 5가지 타입을 지원하는 멀티타입 포스트 작성 화면을 구현했습니다.

- `src/app/editor.tsx` 신규 생성 — 포스트 작성 에디터
  - 타입 선택 가로 스크롤 칩 (에세이/한줄평/로그/인용/컬렉션)
  - 대상 영화 선택 행 (list 타입 제외)
  - 타입별 폼: EssayForm(제목+본문), RatingForm(인터랙티브 별점+한줄), LogForm(포스터+별점), QuoteForm(스타일 인용 박스), ListForm(이름+큐레이터 노트)
  - 에세이 툴바: 스틸 추가 / AI 다듬기 / 임시 저장
