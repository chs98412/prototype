# 포스트 상세 화면 구현 (한줄평/로그/인용/컬렉션)

에세이 외 4가지 포스트 타입의 상세 화면을 동적 라우팅으로 구현했습니다.

- `src/app/post/[kind]/[id].tsx` 신규 생성 — 포스트 상세 (rating/log/quote/list)
  - RatingDetail: 중앙 정렬 포스터 + 큰 별점 + 한줄평 + 저자 행
  - LogDetail: 대형 포스터(210×290) + 미니멀 "— 멘트 없이 기록됨"
  - QuoteDetail: 전체화면 영화 백드롭(어둡게 처리) + 큰 인용문 + 하단 액션 바
  - ListDetail: 포스터 스택 콜라주 + 설명 + 3열 영화 그리드
