# 에세이 상세 화면을 문학적 읽기 뷰로 구현

에세이 상세 화면을 리터러리 매거진 스타일로 구현했습니다. 포스터, 제목, 저자 정보, 본문 단락, 인라인 이미지, 태그, 저자 카드, 댓글 섹션을 포함합니다.

- `src/app/essay/[id].tsx` 신규 생성 — 에세이 상세 화면
  - 포스터 + 영화 제목 + 에세이 제목 + 저자 헤더
  - 좋아요/댓글/북마크 액션 행
  - 본문 단락 (Noto Serif KR, line-height 28)
  - 인라인 이미지 + 캡션
  - ※ 엔드마크, 태그 행
  - 저자 카드 (팔로우 버튼)
  - 댓글 섹션
